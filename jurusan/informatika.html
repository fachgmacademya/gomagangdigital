Fokus Materi & Praktik Informatika

Dalam dunia kerja digital, peserta dari jurusan Informatika tidak hanya dituntut memahami teori dasar komputasi, tetapi juga kemampuan membedah bagaimana sebuah website bekerja dari sisi logika data, navigasi pengguna, hingga bagaimana informasi diproses dan disajikan secara efisien kepada pengguna akhir.

Melalui program magang Pengembangan Website berbasis Digital Marketing, peserta jurusan Informatika akan diasah melalui studi kasus nyata:

1. Logika Alur Website

Merancang diagram alur (flowchart) interaksi pengguna, pemetaan halaman (sitemap), dan logika perpindahan antar section halaman website.

2. Struktur Data Konten

Memahami cara kerja data terstruktur (JSON-LD), Schema.org, serta pemodelan entitas informasi agar mudah dibaca oleh algoritma mesin pencari Google.

3. Filter & Manipulasi Data

Mempraktikkan manipulasi DOM JavaScript untuk filter kategori portofolio, dynamic rendering FAQ, dan penanganan event form secara dinamis.

4. Pemecahan Masalah SEO

Menganalisis performa website melalui audit kecepatan halaman, optimasi hierarki heading semantic, dan logika perayapan robot mesin pencari.

Portofolio yang Dihasilkan

Setiap peserta magang jurusan Informatika akan menyelesaikan proyek mandiri maupun tim yang menjadi bukti portofolio nyata, meliputi:

  • Website profil bisnis/layanan yang menerapkan structured data JSON-LD lengkap.
  • Fitur interaktif filter data dinamis menggunakan JavaScript modern.
  • Laporan audit teknis performa web dan kepatuhan standar SEO dasar.
