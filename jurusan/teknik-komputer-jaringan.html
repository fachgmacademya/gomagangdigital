Fokus Materi & Praktik TKJ

Sebuah website secanggih apapun tidak akan dapat diakses oleh publik tanpa dukungan infrastruktur server yang stabil, konfigurasi DNS yang benar, dan perlindungan keamanan jaringan yang memadai. Siswa SMK dan mahasiswa jurusan Teknik Komputer dan Jaringan (TKJ) memegang peran vital di balik layar publikasi web.

Dalam program magang ini, peserta TKJ akan dibimbing secara langsung mempraktikkan alur infrastruktur web nyata:

1. Setup Web Server Lokal

Mengonfigurasi local development server (Apache / Nginx / Live Server), memahami virtual host, port forwarding, dan pengujian akses antar-perangkat dalam satu jaringan LAN.

2. Pemetaan Domain & DNS

Memahami alur propagasi DNS global, konfigurasi A Record, CNAME, Name Server (NS), dan pengaitan nama domain kustom ke server publik.

3. Sertifikat SSL & HTTPS

Memasang enkripsi SSL/TLS agar seluruh transmisi data pengunjung terlindungi gembok hijau HTTPS, menghindari peringatan bahaya di browser dan meningkatkan ranking SEO.

4. Monitoring Latency & Cache

Mengukur response time server (TTFB), mengonfigurasi browser caching, dan memastikan uptime website terjaga stabil selama 24 jam penuh.

Portofolio yang Dihasilkan

Peserta magang jurusan TKJ akan membuktikan keahlian teknisnya melalui dokumen dan hasil proyek:

  • Laporan konfigurasi live website berdomain aktif dengan sertifikat keamanan SSL/HTTPS.
  • Dokumentasi setup web server lokal dan simulasi pengujian beban jaringan sederhana.
  • Analisis latency jaringan dan rekomendasi optimasi CDN/caching website.
