Pilihan 5 Jurusan Program Magang

Setiap jurusan memiliki materi pembelajaran dan aktivitas praktik yang diselaraskan dengan kurikulum sekolah dan kebutuhan industri digital modern.

Informatika (IF)

Informatika

Fokus pengenalan konsep komputasi, logika pemrograman, alur kerja website modern, pengolahan data sederhana, dan pemecahan masalah algoritma digital.

Materi Praktik:
  • Logika Alur Kerja Web & Sitemap
  • Struktur Data Konten JSON-LD
  • Dasar Algoritma Search Engine
  • Analisis Pemecahan Masalah Digital
Detail Jurusan
Bisnis Digital (BDP)

Bisnis Digital

Fokus pada proses bisnis daring, riset kebutuhan audiens sasaran, perencanaan kalender konten, copywriting persuasif, dan evaluasi performa pemasaran web.

Materi Praktik:
  • Riset Audiens & Pesaing Online
  • Penulisan Copywriting Landing Page
  • Dasar Optimasi Mesin Pencari (SEO)
  • Perancangan Funnel Chat WhatsApp
Detail Jurusan
DKV / Multimedia

DKV / Multimedia

Fokus pada komunikasi visual, prinsip tata letak antarmuka (UI), harmoni tipografi, pengolahan gambar digital, dan optimasi format media modern WebP.

Materi Praktik:
  • Tata Letak Antarmuka UI Responsif
  • Palet Warna Brand & Kontras WCAG
  • Optimasi Aset Gambar WebP & SVG
  • Desain Kartu & Banner Promosi
Detail Jurusan
Rekayasa Perangkat Lunak

Rekayasa Perangkat Lunak

Fokus pada rekayasa teknis kode pembuatan website, penulisan HTML5 semantik, CSS3 responsif, JavaScript interaktif, dan framework Bootstrap 5.

Materi Praktik:
  • Koding Semantik HTML5 & CSS3
  • Grid System Bootstrap 5 Responsif
  • Interaktivitas DOM JavaScript Modern
  • Pengujian Validitas & Clean Code
Detail Jurusan
Teknik Komputer & Jaringan

Teknik Komputer & Jaringan

Fokus pada infrastruktur pendukung website, setup lingkungan server lokal, konfigurasi domain, DNS record, keamanan SSL/HTTPS, dan alur publikasi.

Materi Praktik:
  • Setup Web Server Lokal (Apache/Node)
  • Konfigurasi Domain & DNS Record
  • Protokol Keamanan Enkripsi SSL/HTTPS
  • Monitoring Latency & Uptime Akses
