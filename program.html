Rangkaian Program Pembelajaran Praktik

7 modul pembelajaran yang terstruktur untuk mengasah keterampilan pembuatan website responsif dan implementasi strategi pemasaran digital.

Modul 01 Tahap Perencanaan

Perencanaan & Struktur Website

Memahami kebutuhan proyek digital, menyusun peta situs (sitemap), merancang hierarki informasi, dan membuat wireframe dasar untuk memastikan navigasi halaman intuitif bagi pengguna.

  • Analisis kebutuhan profil dan layanan bisnis
  • Perancangan tata letak sitemap dan hierarki halaman
  • Sketsa wireframe awal tata letak antarmuka
Modul 02 Tahap Front-End

Dasar Kode & Layout Responsif

Praktik langsung penulisan kode HTML5 semantik, CSS3 modern, flexbox, grid system, dan pemanfaatan framework Bootstrap 5 agar tampilan dapat menyesuaikan berbagai ukuran layar perangkat.

  • Struktur semantik HTML5 yang ramah mesin pencari
  • Sistem grid Bootstrap 5 responsif (mobile, tablet, desktop)
  • Kustomisasi variabel CSS tema Maroon & Putih
Modul 03 Tahap UI / Visual

Visual Antarmuka & Aset Grafis

Penerapan prinsip tata letak antarmuka (UI design), pemilihan tipografi, rasio kontras warna standar aksesibilitas, serta optimasi aset media format WebP dan SVG.

  • Penataan visual hierarchy dan jarak elemen (spacing)
  • Pengolahan dan kompresi gambar modern format WebP
  • Penerapan ikonografi vektor SVG untuk ketajaman visual
Modul 04 Tahap Konten

Penulisan Konten Web (Copywriting)

Merancang teks penawaran yang informatif, jelas, dan memikat. Menyusun pesan utama, deskripsi layanan, dan teks tombol tindakan (Call-to-Action) yang berorientasi pada kemudahan komunikasi.

  • Formula penulisan landing page terstruktur (AIDA)
  • Penyusunan headline penawaran yang relevan dengan audiens
  • Penyusunan template pesan pre-filled chat WhatsApp
Modul 05 Tahap Pemasaran

Dasar Optimasi Mesin Pencari (SEO)

Menerapkan kaidah SEO on-page: penulisan meta tag, title tag, penataan hierarki heading (H1-H3), optimasi alt text gambar, serta penyiapan berkas robots.txt dan sitemap.xml.

  • Pemasangan meta description, Open Graph, dan Twitter Cards
  • Penerapan Schema.org JSON-LD (Organization, WebSite, FAQ)
  • Pemeriksaan keterindeksan halaman melalui sitemap.xml
Modul 06 Tahap Infrastruktur

Integrasi & Publikasi Sederhana

Mengenal cara kerja server web, alur pengujian pada lingkungan lokal, konfigurasi domain, sertifikat keamanan SSL/HTTPS, dan pemeliharaan dasar website agar tetap stabil diakses.

  • Pengujian situs di local development environment
  • Dasar konfigurasi domain DNS dan hosting publikasi
  • Penerapan protokol gembok hijau aman SSL/HTTPS
